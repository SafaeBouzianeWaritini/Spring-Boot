# Spring Boot

Ce dépôt regroupe les exemples, exercices et TP réalisés dans le cadre du cours Spring Boot.

## Contenu

Le dossier `Exemples_et_exercices_du_cours` contient les projets suivants :

- **Addition_de_deux_nombres** : premier projet Spring Boot, addition de deux nombres.
- **Exemple_Client** : exemple de gestion d'un client.
- **Gestion_Personnes** : application de gestion de personnes.
- **Person_Application** : application autour de l'entité Person et spring security.

Le dossier `TP1_&_TP2_Spring_Boot` contient le projet suivant :
- **Gestion_pharmacie** : TP de gestion d'une pharmacie.

## Technologies

- Java
- Spring Boot
- Maven
- Eclipse IDE

## Exécution

1. Importer le projet dans Eclipse (**File → Import → Existing Maven Projects**).
2. Lancer la classe principale avec **Run As → Spring Boot App**.
